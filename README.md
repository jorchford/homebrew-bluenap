# Jorchford Bluenap

## How do I install these formulae?

`brew install jorchford/bluenap/<formula>`

Or `brew tap jorchford/bluenap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jorchford/bluenap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
